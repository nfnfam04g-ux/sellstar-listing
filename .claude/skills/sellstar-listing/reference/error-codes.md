# エラーコード一覧（出品エラー列に記録するコードの辞書）

仕様書 付録E（E-7/E-8）の写し。`出品エラー`列にはコードを書き、解説はここを参照する。
回復区分は B列「出品ステータス」に出る語（`ハル`は稼働ログのみ）。

## 回復区分
| 区分 | 意味 | 動作 |
|---|---|---|
| リトライ | 一時的（通信・UI） | 自動リトライ **最大3回** → 超過で `要確認` |
| スキップ | 上流データ未完 | 今回飛ばす。次巡回で再判定 |
| ハル | 続行不能（未ログイン・利用上限） | 下書き保存まで進め巡回停止＋通知。稼働ログへ |
| 要確認 | データ不正（人が直す） | 下書き保存して停止、人を待つ |

## ログ定型フォーマット
`<コード> <一言理由>（<該当列/項目>）<日時>`
例: `E301 状態「美品」が対応表にない（状態）2026-06-08 14:03`

|---|---|---|---|---|---|

| E002 | リトライ | 環境 | 通信タイムアウト | 回線・サーバ遅延 | 自動リトライ→超過で要確認 |

| E004 | 要確認 | 環境 | ヘッダー名が見つからない（列解決失敗） | ヘッダー改名/削除 | ヘッダー名を仕様と突合・修正 |

| E305 | リトライ | 項目転記 | 入力欄が見つからない（UI変化） | セルスタUI変更 | リトライ→継続失敗で要確認（UI追従要） |
